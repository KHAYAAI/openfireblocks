# ISO 27001 ISMS — superseded

This document has been **replaced** by the ISMS pack in [`docs/compliance/isms/`](compliance/isms/README.md).
That pack follows ISO/IEC 27001:2022: clauses 4 to 10, and the 93 Annex A controls in four themes.

The earlier version of this file (in the git history before 11 October 2026) described a target
state as if it were done. For example, it said "CISO appointed", "security committee established
(quarterly meetings)" and "policy communicated to all personnel", none of which had happened. It
also used the 2013 Annex A layout. **Do not use the old version as evidence.** See corrective
action CA-001 in `docs/compliance/isms/08-corrective-actions.md`.
