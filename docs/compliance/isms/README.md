# FORGE CUSTODY information security management system (ISMS)

Version 0.1 (draft), 11 October 2026. **Not yet approved.** Each document here becomes part of the
ISMS only after the approver named in the register below signs it off. Until then it is a draft.

This pack is the documentation for SOC 2 (Security, Availability, Confidentiality, Processing
Integrity), ISO/IEC 27001:2022, GDPR and POPIA. It is built for upload to Sprinto, or to any
compliance platform or auditor. The mapping is in `docs/assurance/COMPLIANCE-MAPPING-SPRINTO.md`.

## What is true and what is a template

These documents were written from the repository, the tests and the evidence files. They do
**not** claim that any person, meeting, record or setting exists unless it does. Where only a
person can supply a fact, the text says **[to complete]**. Leave those markers in until someone
fills them in with something true. An auditor who finds a ticked box with nothing behind it
stops trusting the rest of the pack.

`docs/PHASE3-ISO27001-ISMS.md` was an earlier draft. It claimed appointments and meetings that
never happened and used the 2013 control layout. It has been replaced with a pointer to this
pack. The old text is in the git history.

## What only the owner can do

None of these can be done from the repository. They are listed so they are not forgotten.

1. Sign Sprinto (or an alternative). Connect AWS, GitHub and Google Workspace, and install the laptop agent.
2. Read, change and sign the information security policy and the policies. Have each person acknowledge them.
3. Name the ISMS owner, the Information Officer and the incident lead (02, section 4).
4. Run background checks on anyone with production or key access.
5. Register the Information Officer with the Information Regulator (`privacy/INFORMATION-OFFICER-REGISTRATION.md`).
6. Have counsel review the privacy notice, PAIA manual, DPA and cross-border clauses.
7. Book an independent human-led penetration test that includes the MCP server.
8. Decide whether the GitHub repository should be private. It is **public** today, which contradicts "source under NDA" (see 03, risk R-21).
9. Run the first tabletop and DR test, and record both.
10. Hold the first management review, and arrange an internal audit before the ISO Stage 2 audit.
