# Security awareness training log (template)

ISO/IEC 27001:2022 A.6.3, clause 7.2, 7.3. SOC 2 CC1.4, CC2.2. Objective O-5.

Sprinto's built-in training produces this record automatically; use this template only if
training is delivered another way.

## Programme

| Audience | Content | When |
|---|---|---|
| Everyone | Phishing and social engineering; passwords, MFA and the password manager; handling Confidential and Restricted information; reporting incidents; acceptable use; privacy basics (POPIA, GDPR) | Within 30 days of joining, then yearly |
| Engineers | Secure coding (OWASP Top 10, input validation, authorisation checks); secrets handling; this repository's rules (route inventory, fail closed, DB-enforced controls); dependency risk | Yearly |
| Key custodians / approvers | Ceremony and recovery procedures; approval fraud (urgent requests, changed addresses); freeze | Before taking the role, then yearly |
| Information Officer | POPIA duties, breach notification, PAIA requests | Yearly |
