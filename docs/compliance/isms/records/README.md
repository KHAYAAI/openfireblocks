# Records

These are **templates**. Each control needs a record that shows it working, and an auditor
samples these records. While the repository is public, fill in copies in Sprinto or Google Drive,
not here, because filled-in records contain names and other personal information
(`../09-document-control.md`, rule 7). The exceptions are the vendor register and the asset
inventory below. They are pre-filled with what the repository shows, and hold no personal information.

| Record | Control | Frequency |
|---|---|---|
| [Access review: company systems](ACCESS-REVIEW-COMPANY.md) | A.5.18, CC6.2/6.3 | Quarterly |
| Access review: product organisations | A.5.18, CC6.2/6.3 | Quarterly, **in the console** (Controls > Access review); stored immutably with a SHA-256 of the snapshot |
| [Joiners, movers and leavers](JOINER-MOVER-LEAVER.md) | A.5.11, A.6.1, A.6.5, CC6.2 | Each event |
| [Training log](TRAINING-LOG.md) | A.6.3, CC1.4, CC2.2 | On joining + yearly |
| [Asset inventory](ASSET-INVENTORY.md) | A.5.9, A.7.14, A.8.1 | Quarterly check |
| [Vendor register](VENDOR-REGISTER.md) | A.5.19–5.22, CC9.2 | On change + yearly |
