# Contracts

No smart contracts are deployed in Phase 0 — signing and broadcasting use plain
externally-owned-account (EOA) transactions.

Smart contracts arrive in **Phase 1+**:

- `Paymaster.sol` — a basic EIP-4337 paymaster for gas sponsorship.
- Account-abstraction wallet factories.

Contracts will be built and tested with Foundry. This directory is a placeholder
until then.
