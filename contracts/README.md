# Contracts

## PermissionedToken.sol

A permissioned (security) token: an ERC-20 whose transfers only work between holders the
issuer has admitted, with freeze, pause, capped minting, redemption (burn) and forced
transfer. Its owner is meant to be an organisation's threshold-signed key, so every
administrative act is a transaction that went through the organisation's approval quorum.
See [docs/deployment/TOKENISATION.md](../docs/deployment/TOKENISATION.md).

The gateway verifies what it governs against a compiled artifact
(`services/api-gateway/src/tokenisation/permissioned-token.artifact.ts`, generated by
`node scripts/build-contracts.js`). A test fails if the artifact is not exactly what this
source compiles to, so the contract the platform verifies deployed code against is the
contract people audit.

This contract has **not** been independently audited. It is short (about 200 lines) and
tested on a real EVM, but a security token holding real value needs an audit of this file
before it is deployed on a public chain.
